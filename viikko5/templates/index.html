Dokumentaatio

Repo: https://github.com/flahtinen/Linux | Sovellus: /viikko5/

Pyyntöpolku

Selain -> Nginx (portti 80, /viikko5/) -> Gunicorn/Flask (viikko5-käyttäjä) -> Ollama (127.0.0.1:11434) ja MariaDB (viikko5_chat).

CI/CD-putki

Jokainen push ja pull request ajaa flake8-linterin ja mockatut pytest-testit. Vain main-haaraan menevät onnistuneet ajot deployaavat cPouta-palvelimelle, päivittävät Nginx/systemd-asetukset, käynnistävät uudelleen vain Viikko 5 -palvelun ja tarkistavat /viikko5/health-päätepisteen.

Käyttäjät, tietokanta ja salaisuudet

Palvelu ajetaan ei-kirjautuvalla viikko5-käyttäjällä ja MariaDB-käyttäjällä viikko5_user@localhost. Salaisuudet ovat /etc/viikko5/env-tiedostossa (root:viikko5, 640) sekä GitHub Actions Secrets -muuttujissa.

Mallivalinta ja resurssit

Malli llama3.2:1b valittiin cPouta-instanssin muisti- ja levytilan (free -h, df -h) perusteella. Koska Viikko 4:ssä on replikointi palvelimelle B, Viikko 5 deployataan palvelimelle A (fanni), jossa tietokanta on kirjoitettavissa.

Pyyntöpolku

  
Selain → Nginx (:80, /viikko5/) → Unix-soketti (/run/viikko5/gunicorn.sock) → Gunicorn / Flask (viikko5.service) → Ollama (127.0.0.1:11434) ja MariaDB (viikko5_chat).


  
CI/CD-putki, käyttäjät, Nginx ja resurssit

  
    
    
  • CI/CD: Pull requesteissa ajetaan testit; main-haarassa ajetaan testit ja viikko5/deploy/deploy.sh, joka kopioi koodin, käynnistää viikko5.service-palvelun uudelleen sekä varmistaa soketin ja /viikko5/health-päätepisteen (COMMIT_SHA).
    • 
    
  • Käyttäjät, oikeudet ja salaisuudet: Linux-käyttäjät ubuntu ja viikko5; sovelluskansio /opt/viikko5/app/viikko5 ja soketti /run/viikko5/gunicorn.sock omistuksessa viikko5:viikko5; MariaDB-käyttäjä viikko5_user@localhost oikeuksilla viikko5_chat.*. Salaisuudet säilytetään GitHub Secretsissä ja palvelimen ympäristössä (ei repositoriossa eikä dokumentaatiossa).
    • 
    
  • Nginx: Erillinen /viikko5/-reititys ohjaa liikenteen Unix-soketille vaikuttamatta muihin sivuihin.
    • 
    
  • Malli ja resurssit: llama3.2:1b (1.3 GB), 7.6 GiB RAM (6.9 GiB available), 2.0 GiB swap.
    • 
    
  • Viikko 4 ja replikointi: Tietokanta viikko5_chat toimii paikallisesti fanni-palvelimella (ei replikoitu erilliselle B-palvelimelle).
    • 
    
  • Testit ja opittu asia: Testit ja /viikko5/health läpi; ratkaistu rsync-komennon --no-g --no-o (chgrp / exit code 23) ja Gunicorn-soketin käynnistymisviiveen (502) odotussilmukka.
