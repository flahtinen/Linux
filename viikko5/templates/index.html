Repo: https://github.com/flahtinen/Linux | Sovellus: /viikko5/

Pyyntöpolku

Selain -> Nginx (portti 80, /viikko5/) -> Gunicorn/Flask (viikko5-käyttäjä) -> Ollama (127.0.0.1:11434) ja MariaDB (viikko5_chat).

CI/CD-putki

Jokainen push ja pull request ajaa flake8-linterin ja mockatut pytest-testit. Vain main-haaraan menevät onnistuneet ajot deployaavat cPouta-palvelimelle, päivittävät Nginx/systemd-asetukset, käynnistävät uudelleen vain Viikko 5 -palvelun ja tarkistavat /viikko5/health-päätepisteen.

Käyttäjät, tietokanta ja salaisuudet

Palvelu ajetaan ei-kirjautuvalla viikko5-käyttäjällä ja MariaDB-käyttäjällä viikko5_user@localhost. Salaisuudet ovat /etc/viikko5/env-tiedostossa (root:viikko5, 640) sekä GitHub Actions Secrets -muuttujissa.

Mallivalinta ja resurssit

Malli llama3.2:1b valittiin cPouta-instanssin muisti- ja levytilan (free -h, df -h) perusteella. Koska Viikko 4:ssä on replikointi palvelimelle B, Viikko 5 deployataan palvelimelle A (fanni), jossa tietokanta on kirjoitettavissa.
